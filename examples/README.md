# Examples

Short, self-contained examples of C++ contracts.  Each code block is
followed by links that open it in Compiler Explorer with each compiler that
supports it.

- [Preconditions, Postconditions, and Assertions](basic-contracts.md)
- [A Custom Contract-Violation Handler](violation-handler.md)

## Maintaining the links

The Compiler Explorer links are generated by `bin/update_examples.py`; see
the comment at the top of that script for the marker format.  The compiler
sets and their options are in `celink-profiles.json`, and the generated
`.celink` files and their short-URL caches are in `.celink/`.
